Configuration GitHub

🔑 Token GitHub

Configurez votre token GitHub pour pouvoir modifier les données du site.

Le token doit avoir les permissions 'repo' pour modifier le repository
📋 Comment générer un token GitHub :
  1. Allez sur GitHub.com → Settings → Developer settings
  2. Personal access tokens → Generate new token (classic)
  3. Sélectionnez les permissions : repo
  4. Copiez le token généré et collez-le ci-dessus
